# Webprogrammierung / Aufgabe / Glücksrad

Dies ist eine **Übungsaufgabe** aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *JavaScript*.

Ein kleines Ratespiel nach dem Vorbild der Fernsehshow „Glücksrad“ wird objektorientiert in JavaScript fertigprogrammiert (Buchstaben raten, Punktestand, Soundeffekte).

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
